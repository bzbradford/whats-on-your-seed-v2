## Things to know

- **Daily data job:** `data-update.yml` is a new workflow file, so it is active (the old "Seed database source updates" stays disabled). It commits to `main` as github-actions[bot] and then dispatches `deploy.yaml`. On its first run there's no SQLite artifact on the fork, so it initializes from the committed catalog (expected).
- Catalog split was deferred: Pages serves the 2.8 MB catalog gzipped at ~287 KB. Reasoning in PLAN.md Phase 2.
- Label PDFs are **not** in the repo. Products link to EPA PPLS PDFs (630 of 880 have one). The only committed PDF is the CPN fact sheet (`public/assets/`, generated by `pipeline/build_fact_sheet.py`, needs `uv sync --extra factsheet`).
- The alternative-host cron scripts (`deploy/`) and the legacy JS test runner were dropped from the pipeline; the legacy `.cjs` tests remain in `legacy/tests/` as material for porting test cases.
