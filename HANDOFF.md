## Things to know

- **Weekly data job** (`data-update.yml`, Mondays 06:30 Central): most weeks it finishes in seconds and commits nothing. When it commits, it's as github-actions[bot] with a summary like "Update catalog from EPA: … (2 added, 1 changed, 0 removed)", then it redeploys Pages. Run `git pull` before working.
- The first scheduled run after this redesign will download once (no `source_headers` recorded yet) and commit the new headers plus the updated `automation` text.
- The old "Seed database source updates" workflow stays disabled in the Actions UI; its file is gone.
- Catalog split was deferred: Pages serves the 2.8 MB catalog gzipped at ~287 KB. Reasoning in PLAN.md Phase 2.
- Label PDFs are **not** in the repo. Products link to EPA PPLS PDFs (630 of 880 have one). The only committed PDF is the CPN fact sheet (`public/assets/`, generated by `pipeline/build_fact_sheet.py`, needs `uv sync --extra factsheet`).
